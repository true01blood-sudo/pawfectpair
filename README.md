# PawfectPair

Platformă completă pentru animale de companie: adopții, programări veterinare, marketplace și comunitate.

## Stack
- Next.js (App Router, TypeScript, Tailwind) — `web/`
- Supabase (Postgres, Auth, Storage) — `supabase/`
- Deploy: Hostinger

## Dezvoltare locală
```bash
cd web
npm install
npm run dev
```

Vezi `web/.env.local.example` pentru variabilele de mediu necesare.
